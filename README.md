# brain

Zweites Gedächtnis als Git-Repo aus Markdown-Dateien. Rohes rein, destilliertes Wissen
raus, mit Links zurück auf die Quelle. Gepflegt wird es von Claude, nach den Regeln in
`CLAUDE.md`.

- **Betriebsanleitung:** [`CLAUDE.md`](CLAUDE.md) — liest Claude bei jeder Session automatisch.
- **Einstieg ins Wissen:** [`wissen/README.md`](wissen/README.md) — Stichwortverzeichnis.
- **Was zuletzt passiert ist:** [`wissen/log.md`](wissen/log.md).

## Ordner

| Ordner | Was |
|---|---|
| `00_RAW/` | Posteingang für Rohes. Gitignored, wird leer gehalten. |
| `10_Output/` | Fertige Ergebnisse. |
| `20_Projects/` | Laufende Arbeit, je Projekt ein Ordner. |
| `30_Areas/clients/` | Je Kunde ein Ordner. |
| `40_Resources/` | Nachschlagen. |
| `90_Archive/` | Abgeschlossen. |
| `wissen/` | Das Wiki: destilliertes, projektübergreifendes Wissen. |
| `templates/` | Vorlagen. |

Arbeits-Branch ist `main`. Keine Zugangsdaten im Repo — nur, wo sie liegen.
