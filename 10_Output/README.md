# 10_Output

Fertige Ergebnisse: Abrechnungen, Anschreiben, Rechnungen, Berichte.

## Diese Dateien liegen nur lokal

Der Ordner ist bis auf diese Datei **gitignored**. Was hier entsteht, enthält der Natur
der Sache nach personenbezogene Daten — Namen und Anschriften von Mietern und Kunden,
Bankverbindungen, Steuernummern, Zahlungsverhalten. Dieselbe Begründung, aus der auch
`00_RAW/` und alle `quellen/`-Ordner lokal bleiben.

**Ins Git geht die aufbereitete Notiz, nicht das Dokument.** Beträge, Fristen, Befunde und
offene Punkte stehen in `20_Projects/<projekt>/uebersicht.md` und in `wissen/` — dort ist
das Wissen, das eine spätere Session braucht. Die Dateien selbst liegen beim Empfänger und
in Saschas Ablage.

## Folge für Cloud-Sessions

In einer Session über claude.ai/code ist dieser Ordner leer. Das ist kein Fehler. Wird ein
Dokument gebraucht, muss es in die Session hochgeladen werden; was neu entsteht, geht über
den Datei-Anhang zurück an Sascha.
