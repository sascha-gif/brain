# 00_RAW — Posteingang

Hier landet Rohes: Transkripte, Exporte, Clippings, PDFs. Unverändert, ohne Ordnung,
ohne Namensschema.

Alles in diesem Ordner ist gitignored — nur diese Datei liegt im Repo. Rohdaten sind oft
sensibel und bleiben lokal; ins Git geht nur die aufbereitete Notiz.

Auf Zuruf („sortier RAW ein") liest Claude jede Datei hier, schreibt eine saubere Notiz an
den richtigen Ort, aktualisiert die betroffenen Seiten und räumt das Original weg. Danach
ist dieser Ordner wieder leer — das ist der Punkt.

**Hinweis für Cloud-Sessions:** Über claude.ai/code existiert dieser Ordner nicht, weil der
Checkout nur kennt, was im Git liegt. Einsortieren läuft dort über eine hochgeladene Datei,
der volle Durchlauf lokal über die CLI.
